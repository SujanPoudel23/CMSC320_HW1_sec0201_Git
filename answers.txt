Q1: Why might we consider using Git?

Answer: Git is a version control system, and we should consider using it because it provides
a clean history of any codebase you build while showing collaborators a presentable way of
changes made to a codebase.

Q2: What field could data science be applied to? Give an Example.

Answer: Data science can be applied to the field of meterology. Weather has a lot of data including
temperature, humidity, and many other factors that are pulled from sensors which are used to predict
future weather. The weatherman on TV is using advanced models that take the data in order to create
a prediction. Theoretically, if we knew every single state of every air molecule at every moment,
we could predict weather with 100% certainty.
